# GAM150
A Trimester 2 2025 Project by Tuan(Me), Steven, Sammy and Zejin

What we have achieved:
- An interactable card-game/strategy game where you can utilize the card to defeat enemy, maneuver or protect yourself from attacks.
- Custom made music by me and art by Sammy
- Engine supported ECS

What We could do better:
- A better structure in how the code should work
- Use of event system would have eliminated a lot of confusing messaging problem in the system
- Learn how pre-compiled header actually work would remove most of our major bugs.
- Learn to use C++ effectively with smart pointers, RAII, template, etc...
